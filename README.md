# veforma-pages

Páginas web da Veforma. Cada projeto é independente (próprio `package.json` e `pnpm-lock.yaml`), no mesmo modelo do monorepo da Brindefly.

| Projeto | Propósito | Stack |
|---------|-----------|-------|
| [`brindefly-partner`](brindefly-partner/) | Landing page e fluxo de conexão do app Veforma na loja de aplicativos da Brindefly | Next.js 16 · Cloudflare Workers |

Leia o `README.md` e o `CLAUDE.md` de cada projeto antes de trabalhar nele.
